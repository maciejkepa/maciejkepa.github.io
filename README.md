# maciejkepa.dev

Personal site and technical blog for Maciej Kępa, built with Astro and MDX for deployment on GitHub Pages.

## Stack

- Astro
- MDX content collections
- Custom CSS design system
- GitHub Pages via GitHub Actions

## Structure

- `src/pages/` site routes
- `src/content/blog/` MDX articles
- `src/components/` reusable UI and MDX callouts
- `src/layouts/` base and article layouts
- `.github/workflows/deploy.yml` GitHub Pages deployment

## Domain

The repository is configured for:

- primary site: `https://maciejkepa.dev`
- blog section: `https://maciejkepa.dev/blog`
